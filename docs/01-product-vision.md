# Product Vision

## Vision

Create a simple, developer-first feature management platform that any team can self-host.

## Mission

Help teams release software confidently by giving them complete control over feature availability.

## Product Principles

- Deployment is not Release
- Safe by Default
- Keep It Simple
- API First
- Self-Hostable
- Developer First

## Long-term Vision

Future versions may introduce experimentation, scheduled releases, analytics, and advanced rollout strategies while keeping the core product lightweight.
